How Square connects later

Today the button opens mayan-winds-flagstaff.square.site. The list stays in this browser because Square’s page has its own menu. When the shop is ready, js/square.js holds a SQUARE_CONFIG object — application ID, location ID, and a server URL — and a commented path for the Web Payments SDK and the Orders API. The access token stays on a server. There is no card field on this page.
